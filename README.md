Welcome to **macOS Portfolio OS**, a highly interactive, web-based portfolio designed to replicate the macOS desktop experience. This project serves as my personal portfolio, showcasing my skills, projects, and experiences in a creative and engaging way.

## ✨ Features

- **macOS Window Management**: Draggable, resizable, and minimizable windows.
- **Interactive Dock**: A fully functional dock with tooltips and fluid animations.
- **Live Widgets**: Including a real-time analog clock and weather updates.
- **Glassmorphism UI**: Beautiful frosted glass effects mimicking macOS aesthetics.
- **Bento-style Sections**: Floating interactive UI elements displaying skills, education, and biography.
- **Built-in Apps**: 
  - 🌐 **Portfolio**: An immersive app containing project details and interactive UI.
  - 📝 **Finder**: A file explorer-style interface to browse through my projects.

## 💻 Technologies Used

This project is built using purely native web technologies to ensure maximum performance and lack of dependency overhead:
- **HTML5**: Semantic and structured markup.
- **Vanilla CSS3**: Advanced animations, variables, grid/flexbox, and backdrop-filters.
- **Vanilla JavaScript (ES6+)**: Custom window manager, drag-and-drop logic, and event handling.
